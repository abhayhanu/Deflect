# Deflect, live demo

A support operations agent with a reliability harness. This Space runs the whole thing in one
container: the agent, its MCP tool server, Postgres, Qdrant and the console you are looking at.

The shop, its customers and its orders are made up. Ten tickets are run through the real agent
when the Space starts. Open any of them to see every step, every guardrail check and every tool
call. One refund is waiting in the approval queue.

The code, the eval suite and the write ups are in the main repository:
https://github.com/abhayhanu/Deflect
